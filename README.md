# بوابة الأستاذ — الثانوية التأهيلية عقبة بن نافع

## مكونات المشروع
- `index.html` : استمارة التلميذ الحالية، مع الواجهة والشعارات وحفظ Supabase وإنشاء PDF.
- `teacher.html` : بوابة الأستاذ.
- `supabase.sql` : إنشاء/تأمين جدول `students` بسياسات RLS.
- `student-form.html` : نسخة باسم إنجليزي من استمارة التلميذ.

## بوابة الأستاذ
تتضمن:
- تسجيل الدخول بالبريد وكلمة المرور عبر Supabase Auth.
- عدد الاستمارات.
- عدد الاستمارات المسجلة اليوم.
- عدد الأقسام.
- عدد التلاميذ الذين مثلوا المؤسسة.
- البحث بالاسم/القسم/المستوى/الرياضة.
- التصفية حسب القسم والرياضة.
- عرض تفاصيل كل تلميذ.
- طباعة/حفظ PDF.
- تصدير CSV.
- تسجيل الخروج.

## إعداد Supabase
1. افتح مشروع Supabase المرتبط بالاستمارة.
2. افتح SQL Editor.
3. نفّذ كامل ملف `supabase.sql`.
4. من Authentication > Users أنشئ حساب الأستاذ (Email + Password).
5. لا تستعمل `service_role` أو أي Secret key في ملفات GitHub.

الـ anon/publishable key يمكن أن يظهر في واجهة المتصفح، لكن RLS هو الذي يحمي جدول البيانات. لذلك لا تنشر بيانات التلاميذ نفسها داخل مستودع GitHub.

## نشر GitHub Pages
1. أنشئ Repository جديداً.
2. ارفع محتويات هذا المجلد.
3. اجعل `index.html` في جذر المستودع.
4. من Settings > Pages اختر Deploy from a branch ثم `main` و`/(root)`.
5. بعد النشر سيكون رابط التلميذ هو رابط الموقع الرئيسي.
6. رابط الأستاذ سيكون:
   `/teacher.html`

مثال:
https://USERNAME.github.io/aqba-student-portal/
https://USERNAME.github.io/aqba-student-portal/teacher.html

## ملاحظة أمنية مهمة
GitHub Pages موقع ثابت، لذلك كلمة مرور الأستاذ لا ينبغي أن تكون مكتوبة داخل JavaScript. البوابة هنا تعتمد Supabase Auth، والقراءة من جدول `students` محمية بسياسة RLS للمستخدمين المسجلين فقط.

## الخطوة الأخيرة
بعد رفع الملفات إلى GitHub وتشغيل SQL وإنشاء حساب الأستاذ، جرّب:
1. فتح `index.html` كرابط عام.
2. إرسال استمارة تجريبية.
3. الدخول إلى `teacher.html`.
4. التأكد من ظهور السجل.
5. تجربة «عرض» ثم «طباعة / حفظ PDF».
